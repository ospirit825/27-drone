LicheeRV Nano SG2002 模型转换结果

主文件：first_model_sg2002_int8_mix.cvimodel
平台：SG2002，编译目标 cv181x；Cvimodel 格式版本 1.4.0。
大小约 3.3 MiB；工具报告所需 ION 内存 13.20 MB。
这是 INT8 为主、敏感注意力和姿态解码等算子保留 BF16 的混合量化模型。
使用上传压缩包内全部 50 张图片校准，并完成默认 10 张样本的阈值微调。
纯 INT8 初步试验出现坐标输出截断，未作为交付文件。

输入：images，float32，[1,3,640,640]，RGB、NCHW、像素除以 255。
本模型没有融合图像预处理，需要应用程序自行处理；不能直接输入 JPEG 或 uint8 BGR。
等比例缩放到 640×640 内，空白居中填 114。
校准器采用 int(原尺寸×缩放系数) 计算缩放尺寸；部署应使用相同规则。

输出：output0_Concat_f32，float32；运行时形状 [1,36,8400,1]，逻辑形状 [1,36,8400]。
通道含义：4 个框坐标 xywh、24 类分数、4 个关键点的 xy 坐标。
没有单独 objectness；关键点没有置信度通道。仍需置信度筛选、NMS、坐标还原。
类别顺序见 model_config.json。坐标先在 640×640 预处理图上解码，再减去 padding、除以缩放比例。
此自定义 YOLO26n-pose 模型需要匹配的后处理，不能假定普通 YOLOv8 检测例程可直接运行。

验证：
1. ONNX 到 FP32 MLIR：317 个被比较张量全部通过。
2. 混合量化 MLIR vs FP32 MLIR：输出余弦相似度 0.999942，欧氏相似度 0.989273。
3. 最终 CVIMODEL 在 CV181x 模拟器运行通过；vs 混合量化 MLIR 余弦相似度 0.999983。
上述输出校验使用 calib_img/0000.jpg，是校准样本，不代表独立测试集精度。
没有标签，未测量 mAP 或关键点误差；未连接真实开发板，尚未验证板端 SDK 兼容性和速度。
板端需要匹配 cv181x / SG2002 的 CVI Runtime / TPU SDK，不能使用 RKNN Runtime。
若 SDK 提示模型版本不支持，需要按板端 SDK 版本重编译，而不是更改文件后缀。

压缩包内容：模型、说明、配置、校准表、BF16 混合量化表、成功编译校验日志、原 ONNX 和 50 张量化图片、复现命令。
